#### 2.2.2 关键设计点

- **Trait 形状**：
  ```rust
  #[async_trait]
  pub trait LlmClient: Send + Sync {
      async fn complete(&self, req: CompletionRequest) -> Result<CompletionResponse, LlmError>;
      fn stream(&self, req: CompletionRequest)
          -> Pin<Box<dyn Stream<Item = Result<StreamEvent, LlmError>> + Send>>;
  }
  ```
- **流式选型**：reqwest 0.12 的 `bytes_stream()` → 自己解 SSE。考虑直接用 `eventsource-stream` crate 省事。
- **超时**：硬上限 5 分钟；流式期间无新 chunk 60s 视为超时。
- **错误分型**：thiserror `LlmError { Http, Auth, RateLimit { retry_after_secs }, Stream, Parse, Cancelled }`，传到前端转 string。

#### 2.2.3 验收

- [ ] 单测：mock 服务器响应 200 / 401 / 429 / 5xx 全路径
- [ ] 单测：流式分包重组（含 UTF-8 字节边界、ping、error 事件）
- [ ] 集成测试：完整跑通 Anthropic + OpenAI 至少各一次（手动，用 .env 注入 key）
- [ ] 端到端：前端 LlmCard 输入 prompt → 看到流式 tokens 累积

| Handler | 输入 | 输出 |
| --- | --- | --- |
| TextGenerateHandler | LLM prompt | text |
| CodeGenerateHandler | codegen request | C# 文件 |
| AssetGenerateHandler | asset request | C# + 图片 |

| LogAnalysisHandler | build log | 诊断报告 |

**关键**：handler 需要进度回调。设计：
```rust
#[async_trait]
pub trait Handler {
    async fn execute(&self, input: Input, progress: ProgressSink) -> Result<Output, HandlerError>;
}
pub trait ProgressSink: Send + Sync {
    fn emit(&self, event: ProgressEvent);
}
```
Web 端 ProgressSink 推 WebSocket，Tauri 端推 `app_handle.emit`。
