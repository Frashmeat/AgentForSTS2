## 1. 当前理解

当前 Rust/Tauri 重写已经形成 **桌面端本地工具主链路**：

- `ats-core` 承载领域逻辑、LLM、image_gen、image_proc、knowledge、planning、codegen、platform job、project、audit 等模块。
- `src-tauri` 注册桌面端命令，负责工程文件夹、job 提交/查询/取消、audit、settings、ML rembg prewarm 等桌面能力。
- `src` 前端已有 Dashboard / ModEditor / Batch / Log / Settings 5 个页面。
- `ats-web` 目前只保留 health、knowledge、planning、codegen、llm 与静态资源托管，不是完整 SaaS 平台后端。

因此本阶段不再扩大到 Web/SaaS，而是把桌面端 MVP 从“已实现很多能力”收口为“边界清楚、可验证、文档一致”的阶段成果。
