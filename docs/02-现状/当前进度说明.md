## 2. 当前代码事实

| 范围 | 当前事实 |
| --- | --- |
| Kernel | 稳定 ID/schema/hash、Item/Item Type/field/locale ID、typed failure、BuildInfo 和工程模板合同；不认识 STS2 类型 |
| Runtime | RunRecord v3、ArtifactManifest v3、取消和 provider-neutral ports；无产品中心枚举、无游戏类型分支 |
| Game Context | pinned Pack v3、顶层 `itemTypes` 目录、Contribution Resolver、Truth Snapshot v2、Evidence Query 和 typed capability readiness |
| Workspace | ProjectFolder/OS lock/recents、`.ats/runs-v3`、Resource v1，以及可确定性哈希的 ItemDefinition v1 合同 |
| Feature | 9 个通用 Feature；Plan/Single 统一消费 Pack 顶层类型目录，不再分别复制 Truth query 或 Resource role |
| Adapter | Settings、HTTP model/media、Run/Truth/Resource/Artifact filesystem store、dotnet validation/build 和 ZIP package |
| Desktop/React | 仍是已验收的 Stage 2 transport 和页面；Pack-driven Item Library/editor/readiness transport 从 Order 2 接入 |
| Web/CLI | Web 只提供 health/catalog/SPA；CLI catalog 仍来自共享 9-Feature registry |

Pack v3 顶层 `itemTypes` 是 Mod 类型身份、受限通用字段、required locales、Evidence Queries 和 Resource roles 的唯一真源。`pack.mod-plan-guidance` v3 只提供规划指导；`pack.mod-generate-single` v3 只提供生成指导、验证 Primitive 和输出文件角色。新增类型不应修改 Runtime 枚举，也不应在 React、Plan 和 Single 中再维护平行列表。

ItemDefinition v1 保存稳定 `itemId/itemType`、canonical structured fields、behavior intent、本地化确认/过期状态和精确 Resource version binding。定义使用有序序列化计算 SHA-256；后续 Run/Artifact 必须绑定该 hash，不能从自然语言反推锁定字段。

Capability readiness 由 pinned Pack 与当前 verified Truth 确定性计算：未声明类型不出现；无当前 Truth 时所有已声明类型 blocked；部分 Evidence Query 不命中时只禁用受影响类型并返回 typed query-index blocker；ready 之前不得进入模型调用。

## 3. Prompt 与所有权

```text
Feature Recipe
+ Pack Contribution / selected Item descriptor
+ bounded Truth Evidence
+ Selected Resources
+ Project Context
+ llm.custom_prompt
+ Typed Output Contract
= ModelRequestSnapshot v1
```

跨游戏任务语言属于 Feature Recipe；游戏类型/字段/资源/查询和指导属于 Pack；当前 API 事实属于 Truth；资源版本属于 Workspace；用户补充指令属于运行时设置。代码只保留 role、schema、slot、JSON、安全、截断、脱敏和 typed validation 等协议合同。

Plan result v2 的 `evidenceRequirements` 仍只描述业务证据意图。可执行 `symbols/terms` 查询来自 Pack v3 item descriptor；readiness 与 Single Generate 复用同一查询。Single 将所选类型的 `generatedFiles[].role` 编译为 run-scoped bundle v2 strict JSON Schema。
