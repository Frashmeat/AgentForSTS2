## 2. 当前代码事实

| 范围 | 当前事实 |
| --- | --- |
| 基础合同 | `ats-kernel` 提供 ID/schema/hash、typed actionable failure、BuildInfo 和工程模板合同 |
| Runtime | `ats-runtime` 提供 RunRecord v3、ArtifactManifest v3、取消和 provider-neutral ports；无中心产品 `RunKind/RunResult` |
| Game Context | pinned STS2 Pack v2、Contribution Resolver、Truth Snapshot v2、Evidence Query 和 STS2 工程模板 |
| Workspace | ProjectFolder/OS lock/recents、`.ats/runs-v3` 和统一 Resource v1/version/provenance/selection |
| Feature | 共享 catalog 注册 project.create、plan、resource、single/batch/complex、log、build、package 共 9 个 Feature |
| Adapter | Settings、HTTP model、Run/Truth/Resource/Artifact filesystem store、dotnet validation/build 和 ZIP package |
| Desktop | Stage2Composition、generic Feature submit、Truth import/status、v3 Run get/list/cancel、ProjectSession cancel-and-drain |
| React | v3 transport guards、持久化 Run polling、实际 Feature 页面；旧 stream/store/preview/raw LLM UI 已删除 |
| Web | `/api/health`、`/api/features` 和 static SPA；工程执行明确为 desktop-only |
| CLI | build/deploy/logs/stop 加共享 `features` catalog 输出 |

`resource.prepare` 当前支持 file、Pack default 和 AI media。AI Adapter 支持 OpenAI Images/Chat Completions、取消、typed HTTP failure 与 request-hash provenance；health 的 `mediaGenerationRegistered=true`。真实外部图片 provider 尚未在 WO7 机器门禁中调用，`ml-rembg` 仍是独立的候选 BuildInfo/后处理身份。

## 3. Prompt 与所有权

```text

+ Pack Contribution
+ Truth Evidence
+ Selected Resources

+ llm.custom_prompt

```

Feature Recipe 位于 `crates/ats-features/recipes/`，STS2 内容位于 `game_packs/sts2/stage2-game-pack.json`，当前事实来自 verified Truth。仓库生产代码中已无旧 Prompt bundle、`single_asset_plan`、raw LLM completion/stream 或旧 codegen Prompt 入口。
