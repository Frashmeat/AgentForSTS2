## 3. 已闭合的根因

1. AI 只拥有 Behavior 语义，不拥有游戏原生文件。
2. confirmed localization、Resource、reference、identity、path 和 manifest 均由本地确定性代码产生。
3. Adapter/render/compiler failure 归类为本地缺陷，不进入模型反馈。
4. 每个 Behavior 节点首次请求是 baseline；20 次 shared allowance 只限制额外修订。
5. `semanticRequestCount` 只做实际请求审计；`semanticFeedbackCount` 单独记录额外反馈。
6. 人工反馈从 succeeded source 派生新 Graph，只替换目标 Behavior/Render；原文只在当次 worker 内存存在，Pending/Active human target 不能跨重启 Resume。
7. 旧 generated-file Graph 没有 reader、迁移或 direct-source fallback。

standalone `mod.generate.single` Feature 仍为 12-Feature catalog 的独立能力，但不参与 Composition 生产路径。
