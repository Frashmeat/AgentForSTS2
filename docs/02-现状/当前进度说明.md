## 3. Prompt 与所有权

当前模型请求统一装配为：

```text
Feature Recipe
+ Pack Contribution
+ Truth Evidence
+ Selected Resources
+ Project Context
+ llm.custom_prompt
+ typed output contract
= ModelRequestSnapshot v1
```

Feature Recipe 位于 `crates/ats-features/recipes/`，STS2 内容位于 `game_packs/sts2/stage2-game-pack.json`，当前事实来自 verified Truth。`mod.plan` 的模型输出不作者化 Pack 内部资源角色；`pack.mod-plan-guidance` v2 按 item type 提供角色并由 Feature 确定性写入 Plan result v2。仓库生产代码中已无旧 Prompt bundle、`single_asset_plan`、raw LLM completion/stream 或旧 codegen Prompt 入口。

Plan 的 `evidenceRequirements` 只描述需要证明的事实；STS2 Pack 的每个 item type 通过
`evidenceQueries { symbols, terms }` 声明可执行查询。Single Generate 要求每组查询至少命中
一条当前 Truth，再有界去重地装配请求。用户不再需要在需求中填写内部 Truth symbol。
