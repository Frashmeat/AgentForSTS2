- 缺少 Truth Snapshot 时的图片任务错误仍偏通用；切换工程后 Single Asset 卡片可能残留旧 plan/error。它们不影响已落盘 Run/Artifact 事实，也不阻断当前 readiness gate，但仍需在对应 UI 任务中处理。
- 安装版 E2E 使用确定性本地 LLM/image stub 验证真实桌面和 ML 处理链，不等同外部模型提示词语义质量评测。

自动门禁证明候选构建、测试和机器身份一致性；最终桌面安装/启动、真实 Artifact 发布和锁生命周期另由安装版 E2E 证据及用户明确确认完成。
