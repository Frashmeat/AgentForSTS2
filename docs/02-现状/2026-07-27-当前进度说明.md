## 3. 2026-05-29 后的重要进展

在原桌面端 MVP 收口计划之后，仓库继续完成了以下工作：

- 前端 job ID 进入跨路由 store，任务执行期间切换页面不再丢失进度。
- Knowledge 配置、状态和操作被整理到统一卡片，System 页面职责进一步收敛。
- LLM 与 image generation provider/size 改为稳定的选项控件，同时兼容当前自定义值。
- 设置表单的敏感字段语义得到统一：后端脱敏值不装入 GitHub token/API key 编辑框，未编辑时不产生 patch，明确输入空值时仍可清空。
- 工程锁从“锁文件是否存在”改为 `std::fs::File::try_lock()` 的操作系统独占锁；进程退出后锁自动释放，常驻诊断文件不再造成假死锁。
- 新增前端纯逻辑测试命令，并接入 GitHub Actions 与本地 CI 脚本。
- README、前后端质量规范和 cross-layer skill 中的失效或过时说明已在工作区修正。

其中最后四项属于当前未提交工作区变更，尚未形成 Git commit。
