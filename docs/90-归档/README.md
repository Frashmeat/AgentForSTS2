## 使用规则

- 归档材料不代表当前实现，不作为新任务的唯一依据。
- 历史路径、命令、接口和状态必须结合当前代码、总览、现状与当前方案核实。
- 归档原文原则上只修复链接或补充归档说明，不继续追加任务进度。
- 如果历史结论重新生效，应把稳定事实提炼到当前文档，而不是把旧文档移回有效区。
