## 4. 已修复问题的原始现场

### 4.1 事实扫描只覆盖前 2,000 个文件

最新游戏反编译产物有 3,425 个 C# 文件，但 `Sts2CodeFactsProvider` 的 `MAX_FILES` 固定为 2,000。所有真实查询均返回以下 warning：

```text
已扫描到 MAX_FILES=2000 个 .cs 文件上限，其余被跳过。
```

精确查询 `NSettingsScreen` 时，只返回 BaseLib patch，未返回实际存在的 `MegaCrit.Sts2.Core.Nodes.Screens.Settings.NSettingsScreen` 游戏类。这证明截断已经造成真实知识遗漏，不只是理论风险。

### 4.2 在线 BaseLib 刷新被凭据阻断

- 未认证 GitHub API 请求返回 `403 rate limit exceeded`。
- 使用当前本地配置中的 GitHub token 返回 `401 Bad credentials`。
- handler 按设计把 BaseLib 失败降级为 warning，game manifest 仍正常写入；但无法形成在线更新后的 `fresh` 完整知识库。
- 本轮只确认 token 已配置和失败状态，没有记录或输出 token 内容。
