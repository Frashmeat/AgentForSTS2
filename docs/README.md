# 文档知识库总索引

> 文档定位：本文是 `docs/` 的唯一导航入口，负责区分稳定知识、当前事实、当前方案与历史材料。
>
> 事实依据：当前 `rust` 分支代码、Trellis 工作流和 2026-07-29 确认的文档治理原则。
>
> 权威入口：项目协作规则见仓库根目录 `PROJECT_SPEC.md`。
>
> 最后更新：2026-07-29

## 核心原则

`docs/` 不管理具体任务。任务的 PRD、状态、执行记录、审查和验证过程统一由 `.trellis/` 管理；只有形成长期有效的项目知识时，才回写本知识库。

## 目录结构

```text
docs/
  README.md
  01-总览/
  02-现状/
  03-当前方案.md
  90-归档/
```

## 阅读顺序

1. 先读根目录 `PROJECT_SPEC.md`，确认协作规则和验证边界。
2. 需要理解系统时，读 [`01-总览/README.md`](./01-总览/README.md)。
3. 需要判断当前能力和缺口时，读 [`02-现状/当前进度说明.md`](./02-现状/当前进度说明.md)。
4. 需要理解当前方向和完成标准时，读 [`03-当前方案.md`](./03-当前方案.md)。
5. 只有追溯背景时才进入 [`90-归档/README.md`](./90-归档/README.md)。

## 维护规则

- 不为单个任务在 `docs/` 新建计划、决策、审查或验证文档。
- 具体任务使用 `.trellis/tasks/<task>/prd.md`，完成后按 Trellis 工作流归档。
- 稳定架构变化更新 `01-总览/`；代码事实变化更新 `02-现状/`；阶段方向变化更新 `03-当前方案.md`。
- 被替代的文档移动到 `90-归档/`，不与当前入口并列。
- 修改目录或文件名时，同步更新 `PROJECT_SPEC.md`、相关 README 和仓库内引用。
